# Hospital-Emergency-Room-Power-Bi
Power BI Hospital Emergency Room Dashboard
## Project Overview

This project presents an interactive *Hospital Emergency Room Dashboard*
created using Microsoft Power BI.

The dashboard helps analyze emergency room activity, patient visits,
waiting times, satisfaction levels, demographics, and overall hospital
performance.

## Project Objectives

- Analyze emergency room patient visits
- Monitor patient waiting time
- Analyze patient satisfaction
- Understand patient demographics
- Identify busy periods and trends
- Provide useful insights for hospital management

## 📌 Key KPIs

- Total Patient Visits
- Average Waiting Time
- Patient Satisfaction Score
- Number of Referrals
- Administrative vs Non-Administrative Visits
- Patient Age Group Analysis

## 📈 Dashboard Features

- Interactive filters and slicers
- Patient demographic analysis
- Monthly/weekly visit trends
- Waiting time analysis
- Patient satisfaction analysis
- Referral analysis
- Emergency room performance overview

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset
- Data Visualization

## 🔄 Data Preparation

The dataset was cleaned and transformed using *Power Query*.

Steps included:

1. Data cleaning
2. Handling missing values
3. Data type correction
4. Data transformation
5. Data modeling
6. Creating DAX measures
7. Dashboard visualization
